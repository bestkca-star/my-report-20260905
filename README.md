# 성장 리포트 — 골격

**이것은 완성된 앱이 아닙니다.** 파일과 함수는 다 있고 **본문이 비어 있습니다.**
8주차 5일 동안 여러분이 자기 데이터로 채웁니다.

레퍼런스(완성본)는 따로 있습니다. 막히면 **화면을 먼저 보고**, 그래도 안 되면 코드를 봅니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

**"★ Day2 실습 A에서 채웁니다"** 같은 안내 카드가 뜹니다.
채우는 대로 그 자리부터 화면이 살아납니다.

자기 데이터가 있으면 그것을 넣으십시오 — parquet · csv · 엑셀 다 됩니다.

> **왜 데이터를 안 넣어 두었는가** — 내 데이터를 앱에 연결하는 것이 8주차의 첫 관문입니다.
> 미리 들어 있으면 그 단계를 건너뛰게 됩니다. 자세한 것은 `data/README.md` 에 있습니다.

## 내 도메인으로 옮기는 순서

1. 파일을 `data/` 에 넣는다 — **parquet · csv · 엑셀** 다 됩니다
2. `core/config.py` 의 `TABLES` 에 **파일명(확장자 제외)** 을 적는다
3. 같은 파일의 `FUNNEL_STEPS` 를 내 단계로 바꾼다
4. 앱을 켠다 → **깨진다**
5. `core/metrics.py` 의 컬럼명을 하나씩 맞춘다

**4번에서 깨지는 것이 정상입니다.** 한 번에 되면 오히려 뭔가 안 바꾼 것입니다.

> `config.py` 를 다 바꿔도 끝나지 않습니다. 컬럼명은 `metrics.py` 안에도 박혀 있습니다.
> ★ 표시를 따라가며 하나씩 고치는 것이 이식 작업의 절반입니다. → `DESIGN.md` §4-6

큰 데이터는 parquet 이 훨씬 작고 빠릅니다. `df.to_parquet("data/내테이블.parquet")`

## 코드를 직접 쓰지 않아도 됩니다

**채우는 것은 Claude Code 몫입니다.** 여러분이 하는 일은 **무엇을 결정할지 판단하는 것**입니다.

각 빈자리에는 판단 기준이 주석으로 적혀 있고, Claude 가 그것을 읽고 씁니다.
그래서 짧게 시켜도 됩니다.

```
core/metrics.py 의 funnel() 을 채워줘.
내 퍼널 단계는 [   ] 이고 그레인은 [   ] 이다.
```

**결정은 여러분이 하고, 타이핑은 Claude 가 합니다.** 결정한 것을 프롬프트에 적어 주십시오.
