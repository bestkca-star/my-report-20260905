## 6 — 유지 퍼널 계산  ⚠ 아직 안 정함

```

  결과수신    — 결과 전항목 수신 이벤트가 있는 검진 건
  관측창닫힘  — 그중 재검_90일내 가 NULL이 아닌 건 (90일이 실제로 지난 건)
  재검없음    — 그중 재검_90일내 = False 인 건

★ 계산한 뒤에 이것도 확인해줘:
  앞 단계를 거치지 않고 다음 단계에 나타난 대상이 몇 건인가.
  많으면 이건 퍼널이 아니라고 말해줘.
```

⚠ **위 세 단계는 확정이 아니다.** 후보 8개 중 위반 0으로 확인된 조합을 초안으로 적었을 뿐이다.
심사유의 갈래(심사유의 / 심사유의없음)나 항목 수로 짜는 안도 있다. 고르는 것은 내 몫이다.

## 7 — 지표 카드

```
core/metrics.py 의 kpis() 와 monthly() 를 채워줘.

지표는 이 셋이다. 넷째는 아직 안 정했으니 넣지 마.
  심사유의율   — 심사유의여부=True 건수 ÷ 결과 수신 건수
  경계선 비율  — 경계선여부=True 건수 ÷ 심사유의 건수 (분모가 수신 건이 아니다)
  재작업률     — 재검_90일내=True ÷ 재검_90일내가 NULL이 아닌 건
                (관측 창이 안 닫힌 건을 분모에 넣지 마라)

계산식은 한 곳에만 적고 kpis() 와 monthly() 가 그것을 함께 쓰게 해줘.

monthly() 는 월이 아니라 분기로 잘라줘.
  월로 자르면 수신이 66~100건뿐이라 변동이 전부 표본 노이즈다(동질성 p=0.271).
  분기 기준은 결과 수신일이다.
열 이름은 kpis() 의 지표 이름과 같게 해줘. 그래야 스파크라인이 그려진다.

만든 뒤 36.15% / 22.83% / 9.94% 와 대조해서 맞는지 보여줘.
```

## 8 — 임계값 넣기

```
core/config.py 의 THRESHOLDS 를 채워줘.

  심사유의율  경고 29 미만 또는 43 초과 · 위험 25 미만 또는 47 초과
              — 근거: 헛경보율 4.0%가 되도록 잡은 값. 양방향이다.
                낮아지는 것도 높아지는 것도 판정 운영이 흔들렸다는 신호다.
  경계선 비율  미정 — 값을 지어내지 말고 주석으로 자리만 남겨줘
  재작업률     미정 — 높을수록 나쁜 지표라는 것만 주석에 적어줘

근거는 주석으로 같이 남겨줘.
판정은 분기 단위로 한다는 것도 주석에 적어줘.

그리고 metrics.status_of() 는 지금 한쪽만 본다. 상한도 읽게 두 줄을 더해줘.
안 그러면 심사유의율이 48%여도 "정상"으로 뜬다.

MIN_SAMPLE 은 200 그대로 둔다 — 근거는 명세 4행의 "분기 최소 200건"이다.
```

## 9 — 최근 구간 확인

```
가장 최근에 들어온 검진 건들의 전환율을 따로 보여줘.

- 시작 시점은 의뢰일이다. 이벤트 일자로 묶지 마라.
- 월별로 묶고, 각 묶음의 다음 단계 도달률을 보여줘
- 먼저 의뢰일부터 각 단계까지 걸리는 일수(중앙·p99·최대)를 재고,
  그 최대치만큼 시간이 지난 건이 몇 %인지도 같이 보여줘

최근 묶음의 값이 낮다면, 그게 성과 문제인지
아니면 아직 갈 시간이 없어서인지 판정해줘. 추측하지 말고 재서 판정해줘.
```

## 12 — 퍼널 표를 시각화

```
pages/2_대시보드.py 에 퍼널 표를 st.dataframe 으로 하나 추가해줘.
기존 퍼널 차트는 그대로 두고, 그 아래에 표로도 보여준다.

column_config 를 이렇게 준다.
- 단계: TextColumn
- 도달 수: NumberColumn(format="%,d")
- 단계 전환율: ProgressColumn(min_value=0, max_value=1, format="percent")
- 누적 전환율: ProgressColumn(min_value=0, max_value=1, format="percent")

funnel() 이 이미 0~1 로 돌려주므로 100으로 나누지 마라.
format 에 "%.1f%%" 를 쓰지 마라 — printf 형식은 100을 곱하지 않아서
0.8952 가 "0.9%" 로 뜬다.

hide_index=True 로. 폭은 use_container_width 가 아니라 width="stretch" 로 해줘
(use_container_width 는 2025-12-31 폐기됐다).
```

## 13 — 탭 + fragment

```
pages/2_대시보드.py 의 퍼널 영역을 이렇게 바꿔줘.

1. st.tabs(["획득 퍼널", "유지 퍼널"]) 로 탭 둘을 만든다
2. 각 탭에서 그리는 부분을 함수로 빼고 @st.fragment 를 붙인다
3. 그 함수 안에 기간 필터(시작월~끝월)를 둔다
   기준은 의뢰월이다. 이벤트 일자로 자르면 접수는 구간 안이고 수신은 밖인
   건이 통째로 빠져 전환율이 낮게 나온다.
4. 필터를 바꿔도 함수 안만 다시 그려지는 걸 확인할 수 있게,
   함수 맨 위와 페이지 맨 위에 각각 st.caption 으로 현재 시각을 찍어줘
   (확인용, 나중에 지운다)

주의: 계산 함수에는 현재 시각을 넣지 마. 화면에 찍는 것만이다.
AppTest 로는 조각 격리를 확인할 수 없으니, 확인 못 했으면 못 했다고 말해줘.
```
